# Tech Job & Skill Matching System 🤖

An AI-powered web application that analyzes job descriptions and predicts the best skill match for developers and tech candidates, helping candidates bridge skill gaps and align with job requirements.

---

## 📍 Live Demo

[View Live Project](https://tech-job-and-skill-matching-system.vercel.app/)

---

## 🛠 Tech Stack & Architecture

- Frontend: React, TypeScript, Vite, Tailwind CSS
- Backend / Machine Learning: Node.js, Python, Streamlit
- ML & Data Processing: Scikit-Learn, Pandas, NumPy
- Deployment: Vercel

---

## 🌟 Key Features

-  Job & Resume Skill Analysis: Extract required technical skills from job descriptions.
-  Match Score & Gap Analysis: Calculate compatibility ratings and highlight missing skills.
-  Interactive UI: Dynamic charts and visualizations to display skill breakdown and metrics.
-  Seamless Integration: Fast and responsive client interface built with React & Vite.
